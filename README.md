# Sukanya Sarkar – Portfolio

A static site built on the SnapFolio template (Bootstrap 5). It has no PHP and no build step.

## Run locally
Open `index.html` in a browser.

## Before going live
Replace these placeholders in `index.html`:
- `[EMAIL]` (it appears several times, including the contact form's `data-email`), `[PHONE]`, `[LINKEDIN_URL]`, `[INSTAGRAM_URL]`
- `[Start year]`, `[Expected completion year]`, `[College name]`, `[City]`, `[School name / Board]`, `[Year]`
- Photo: put her photo at `assets/img/profile/` and swap `profile.svg` in the three `<img>` tags
- Skill percentages are estimates, so adjust them as needed

## Deploy
Push to GitHub, then import the repo in Vercel. Choose framework preset "Other" and leave the build settings empty.
